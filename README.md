# 🎓 Student Record Manager

A simple and intuitive application to manage student data, track academic performance, and monitor attendance.

## 🚀 Quick Start
1. **Clone:** `git clone https://github.com/ste-lla-mina/student-recorder.git`
2. **Install:** `npm install`

## ✨ Key Features
* **Student Directory:** Add, edit, and remove student profiles.
* **Search:** Filter records by Name, ID, or Class.

## 🛠️ Tech Stack
* **Backend:** Node.js / Express
* **Database:** MongoDB
